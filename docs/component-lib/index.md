## 有哪些难点

- 规范
  - 组件库 api 定义规范（开发者和使用者间的统一）
  - 设计规范一致性问题（开发者与设计间的统一）
  - 组件库版本、分支规范、文档规范（开发者内部的统一），主要是语义化版本规范，解决多版本开发维护难度大，升级复杂问题。
- 流程
  - 问题抛出到解决的流程
  - 开发贡献流程（CBB 建设流程）
- 技术
  - 组件库分层
  - 组件库技术点
    - 样式 token 设计统一（主题定制）
    - 样式隔离方案（样式前缀）
    - 按需加载方案（js/css 的按需加载）
    - 组件库测试
    - 组件难点
      - 虚拟滚动
      - tree 卡顿
  - 其他尝试
    - 自动引入方案预研
    - monorepo 方案
    - class => hooks
    - 自动化测试 id 问题
  - 组件开发心得
  - 组件库管理平台
    - nextjs ssr 方案
    - 组件运行时
      - react 运行时，代码哈夫曼压缩
      - 基于 bytemd 的运行时改造
